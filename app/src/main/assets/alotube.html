Cuenta de Google

ID de cliente OAuth (Google Cloud)
Cómo conseguir el ID de cliente
  1. En console.cloud.google.com crea un proyecto.
  2. En "APIs y servicios" activa YouTube Data API v3.
  3. En "Pantalla de consentimiento de OAuth" elige tipo Externo y añade tu cuenta en Usuarios de prueba.
  4. En "Credenciales" crea un ID de cliente de OAuth de tipo Aplicación web.
  5. En "Orígenes de JavaScript autorizados" añade la dirección desde la que abres AloTube (por ejemplo http://localhost:8000 o https://tuusuario.github.io). No sirve abrirlo como archivo.
  6. Pega aquí el ID de cliente y toca Conectar. Google avisará que la app no está verificada: es tu propia app, continúa.
